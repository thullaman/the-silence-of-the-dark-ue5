# The Silence of the Dark

A first-person horror game prototype built in Unreal Engine 5.

## Overview
This project focuses on atmosphere-driven horror through environmental design rather than scripted jump scares. The prototype explores lighting, fog, terrain, and sound to create tension and unease.

## What I Worked On
- Environment creation (terrain, foliage, lighting)
- Fog and low-visibility atmosphere setup
- First-person player controller
- NavMesh setup for AI movement
- Enemy character placement and early AI logic
- Collision and basic interaction systems
- animations on enemy mesh (idle, running)

## Current Status
This project is an **in-development prototype**.
Enemy AI movement is under iteration, and gameplay objectives are planned for future milestones.
